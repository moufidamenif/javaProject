# 📚 Educational Platform – Java Web App

This is a dynamic web-based educational platform developed as part of an academic project. It allows users to register, explore courses, and interact with content using a traditional Java EE stack.

## 🚀 Features

- User registration and login system
- Course listing and enrollment
- Admin and user roles
- Session tracking via listeners
- Dynamic pages using JSP
- Data persistence using Hibernate ORM
- Clean DAO/Controller architecture
- MVC pattern for maintainability

## 🛠️ Tech Stack

- **Java EE** (Servlets, JSP, Listeners)
- **Hibernate ORM**
- **MySQL** (Relational Database)
- **JDBC**
- **Maven** (for dependency management)
- **Apache Tomcat** (Servlet container)
